# 초기 구축 검증 기록

2026-09-16 기준.

## 확인 완료

- Python 3.13 가상환경 인터프리터에서 표준 라이브러리 테스트 18개 통과
- Python 3.14에서도 동일한 기본 테스트 통과
- 예시 lockfile 비교와 분석 요청 JSON 생성
- 분석 결과·모델 미연결 시 `incomplete` 출력
- 신규 의존성·미지원 출처·같은 버전 아카이브 변경 시 미완료 처리
- 요청 식별자·특징 스키마 불일치, 결과 중복·누락·실패 처리
- 기존 입력 파일을 출력으로 덮어쓰지 않는 동작
- Python 소스 문법과 pyproject TOML 파싱

## 아직 실행하지 못한 검증

- native LightGBM 모델 통합 테스트 2개: ML 의존성 미설치로 skip
- Ruff lint·formatter, wheel/sdist 빌드
- GitHub Actions 서버 실행, 실제 학습 모델·분석기·데이터를 이용한 탐지 검증

제한 환경에서 Python 임시 디렉터리 ACL 오류로 pip 준비가 실패했다.
프로젝트 .venv 설치에 대한 사용자 승인은 받았지만, 자동 승인 검토 서비스가
처리 용량 오류로 권한 확장 실행을 거절해 의존성 설치를 완료하지 못했다.
의존성 설치 후 README의 전체 검증 명령을 실행하고 이 기록을 갱신한다.

테스트 자료는 악성코드가 없는 합성 자료다. 테스트 통과는 탐지 성능을 뜻하지 않는다.
