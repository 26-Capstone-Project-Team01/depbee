실행할 수 있는 것

  • 업데이트 검사(update): 전체는 위의 "전체 업데이트 검사", 직접 의존성 하나는 패키지 목록 그 행의 "이 패키지 업데이트 검사", 여러 개는 업데이트 화면의 "패키지를 지정해 업데이트 검사"입니다. CLI의 depbee update, depbee update 이름과 같습니다. 대상을 확인한 뒤에 시작하고, 끝나면 검토·반영 화면이 열립니다.
  • lockfile 변경 검사(scan): 지금 package-lock.json과 Git HEAD의 차이를 검사합니다. CLI의 depbee scan . --extract와 같습니다.
  • 패키지 한 버전 검사(check): 대시보드에서는 실행하지 않고 CLI에서만 실행합니다. lockfile 없이 그 버전 하나만 읽어 검사하며 프로젝트 파일과 이력을 바꾸지 않습니다. 예: {{ check_example if check_example is not none else "depbee check 이름@버전" }}
